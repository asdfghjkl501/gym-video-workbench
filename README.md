# gym-video-workbench# 健身房短视频运营工作台
> 📌 个人原型项目｜
> 技术栈：HTML / CSS / JavaScript
> ⚠️ 仅前端演示原型，**无后端、不对接真实API**，数据存储在浏览器本地

## 📋 项目简介
来源于真实短视频运营工作痛点，面向健身房本地账号打造的一体化SaaS风格工作台。
采用独特环形SVG导航，完整覆盖短视频生产全链路：爆款库、选题池、脚本生成、标题文案、口播文案、分镜建议、封面文案、发布排期、转化目标、账号数据分析。

设计理念：**区分高频操作与低频操作**
- ✨高频：亮/深色主题切换，点击设置扇区唤起外侧弧形副面板快速切换
- 📄低频：品牌配置、使用说明、业务设置，放置时钟卡片内「更多设置」入口

## 🎯 核心功能
1. **环形SVG导航首页**
- 环形扇区作为功能入口，跳转对应业务记录页面
- 设置扇区禁止页面跳转，点击展开外侧弧形副面板
- 保留扇区原生hover放大高亮效果，副面板自适应跟随主扇区位置
- 鼠标完全离开合并热区，副面板自动平滑收起；点击其他扇区自动关闭面板

2. **明暗主题切换**
- 副面板内为纯白、纯黑两个圆形按钮，无文字无图标
- 当前生效主题按钮拥有蓝色外圈激活状态
- 主题配置存入`localStorage`，刷新页面自动记忆；读取失败自动降级浅色模式
- 完整页面全部组件跟随主题同步适配

3. **业务模块**
- 支持记录新增、编辑、查看检索，内置模拟演示种子数据
- AI脚本/标题生成仅预留UI入口，未对接接口

4. **边界容错适配**
- 进入业务展开页面，自动禁用设置副面板交互
- 窗口宽度小于1050px，自动隐藏副弧形组件，防止SVG错位错乱
- 全部显隐仅使用`opacity`透明度过渡，规避缩放位移带来图形变形
